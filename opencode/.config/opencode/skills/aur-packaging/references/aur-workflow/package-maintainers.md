# Package Maintainers

Source: `/usr/share/doc/arch-wiki-zh-cn/html/zh-cn/软件包维护者.html`

## Purpose

Explains the formal Arch Package Maintainer role and its relationship to high-quality AUR work.

## Operational guidance

- A Package Maintainer is an official Arch project role, not simply an AUR package owner.
- Maintained, clean, high-quality AUR recipes are evidence of packaging ability.
- The role requires demonstrated shell, packaging, research, and community skills.
- Treat this page as governance context, not as a routine PKGBUILD authoring procedure.
