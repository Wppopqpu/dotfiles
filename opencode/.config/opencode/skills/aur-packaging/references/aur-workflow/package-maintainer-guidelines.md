# Package Maintainer Guidelines

Source: `/usr/share/doc/arch-wiki-zh-cn/html/zh-cn/软件包维护者指导原则.html`

## Purpose

Formal Arch Package Maintainer responsibilities for AUR oversight and official repository promotion.

## Operational guidance

- This role is distinct from ordinary AUR package ownership.
- Review submissions for malicious content and packaging-standard compliance.
- For promotion of an AUR package to `extra`, increment `pkgrel` so current AUR users receive an upgrade.
- Rewrite AUR history only when authorized and after a backup; force-push and identity rewriting are exceptional administrative operations.
- Do not encode disputed or governance-specific admission criteria as general AUR package rules.
