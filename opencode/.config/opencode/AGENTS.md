# output rules

-   Use **Simplified Chinese** when speaking to user.
    Use **English** when coding or documenting.
    **Simplified CHinese** is preferred when writing tex doc.
    **Except**: User requests you explicitly.

-   Always use the code style in existing files.
    Add **necessary** comments, doc comments, etc.

-   If you claim or state something, **find some supporting evidences**,
    unless you are **pretty sure**.
    For example: test result, documentation.

-   Follow the plan produced (if there is one), or abort building
    and tell the user what need to be changed in the plan.

-   Make sure that the changes can be easily tracked by git.
    Do not use git without permission. Instead, tell the user what is changed.
